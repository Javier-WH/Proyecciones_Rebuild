GUÍA DE CAPTURAS PARA EL MANUAL DE USUARIO
==========================================

Guarde cada captura en esta carpeta con el nombre exacto indicado
(el manual ya las referencia con esos nombres).

Cómo capturar en Windows: Win + Shift + S → recorte la zona → Ctrl+V
en Paint → Guardar como PNG con el nombre indicado.

CONSEJOS
--------
- Capture con datos reales si es posible (se ve más profesional),
  pero verifique que no aparezcan datos sensibles que no deban difundirse.
- Use PNG. Si la captura queda muy ancha, recorte la zona relevante.
- Después de guardar las imágenes aquí, abra manual-usuario.html en el
  navegador y presione Ctrl+P → "Guardar como PDF" para generar el manual.
